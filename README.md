# Kikmou

I maintain [Quantum Trading](https://github.com/kikmou1/quantum_trading), an open-source Python research toolkit for comparing classical and quantum-inspired portfolio optimization methods.

The project includes walk-forward backtesting, a trading simulator, an interactive dashboard, reproducible offline examples, and tests. Its quantum-inspired methods run on classical hardware; the [limitations](https://github.com/kikmou1/quantum_trading#limitations) explain the assumptions and known biases.

- [Explore the project and try the offline example](https://github.com/kikmou1/quantum_trading#quick-start-offline)
- [Read the contributing guide](https://github.com/kikmou1/quantum_trading/blob/main/CONTRIBUTING.md)
- [View releases](https://github.com/kikmou1/quantum_trading/releases)

Contributions, reproducible bug reports, and feedback on the methodology are welcome.
